## 一、发明/实用新型名称

**名称：一种基于轨道动力学约束预测模型的卫星遥测参数差分压缩编码方法**

---

## 二、所属技术领域

本发明涉及卫星工程技术与数据压缩技术交叉领域，特别是涉及一种将卫星轨道动力学模型、热力学模型和电气工作特性模型融合于遥测数据压缩编码过程的预测差分压缩方法。该方法通过在星地两端共享物理预测模型，利用模型预测值与实际测量值之差（残差）代替原始测量值进行编码传输，显著降低遥测数据编码位宽，从而提升遥测信道有效载荷率。

---

## 三、现有技术（背景技术）

**背景技术：**

**1. 差分脉冲编码调制（DPCM）的局限性**

现有遥测数据压缩中最常用的无损压缩算法是CCSDS 121.0-B定义的差分脉冲编码调制（DPCM）结合Rice编码。DPCM通过传输相邻样本差值（简单一阶差分）来减小编码位宽。然而，DPCM仅利用"相邻两点差值"这一极简预测模型（预测值=上一个采样值），对于卫星遥测参数中具有物理规律性的变化（如随轨道周期变化的温度场、随轨道高度变化的大气阻力加速度等），简单一阶差分的预测精度不足，残差仍然偏大，压缩效果有限。

**2. 卫星遥测参数的物理可预测性未被利用**

卫星平台遥测参数的变化规律与卫星运行的物理环境深度耦合：

- **热控温度**：受太阳辐射、地球红外辐射、卫星内部耗散热的共同影响，温度变化遵循可用轨道根数推算的热平衡方程，具有以轨道周期为基本单元的周期性规律（约90分钟/圈）；
- **电源系统参数**：太阳帆板输出功率随卫星对日角度变化，地影期间功率骤降，出影后功率恢复，变化规律与轨道几何关系高度相关；
- **姿态控制参数**：姿态角速度、动量轮转速等参数在正常姿态控制下遵循控制律方程，可由状态方程预测；
- **轨道参数**：轨道高度、轨道速度等参数在J2摄动、大气阻力等作用下缓慢演化，完全可由轨道动力学模型预测。

上述物理规律性意味着利用相应的物理模型作为预测器，可以获得远小于简单差分的残差，从而实现更高效的编码。然而，现有遥测压缩方法均采用通用数学预测器（如线性外推、LPC线性预测编码），未融合卫星特有的物理模型知识，是重要的技术空白。

**3. 自适应Golomb-Rice编码的不足**

Golomb-Rice编码（CCSDS 121.0-B采用的编码方式）对残差值的分布假设为指数分布（Golomb编码）或几何分布（Rice编码），Rice参数k需根据残差方差自适应调整。但现有方案中Rice参数k的调整粒度粗糙（通常以固定块长度统计一次），不能实时跟踪遥测参数在不同轨道段（如入影/出影边界、轨道机动段等）的快速波动，导致编码效率低于最优值。

## 四、发明/实用新型内容

### 1. 要解决的技术问题

本发明要解决的核心技术问题是：现有遥测数据压缩方法采用通用数学预测器，未利用卫星遥测参数变化规律与物理运行环境的深度耦合关系，导致预测残差偏大、编码位宽偏高，压缩率不足。

具体子问题：

（1）如何将轨道动力学模型、热力学简化模型和电气特性模型嵌入遥测压缩编码器，作为高精度预测器使用；

（2）如何保证星地两端使用完全相同的物理预测模型（模型同步），使预测值一致，从而正确还原原始测量值；

（3）如何设计自适应残差编码方案，在不同轨道段（预测精度差异大）下动态调整编码参数；

（4）如何处理模型预测精度不足（如轨道机动期间、异常事件期间）时的安全回退。

### 2. 为解决技术问题而采用的技术方案

**技术方案描述：**

本发明提出一种基于轨道动力学约束预测模型的遥测参数差分压缩编码方法（PDC-OM，Predictive Differential Coding with Orbital Model）。该方法将轨道根数驱动的物理模型作为预测器，传输实际测量值与模型预测值之间的残差（而非相邻采样差值），并结合自适应Golomb-Rice编码对残差进行变长编码，实现遥测参数的高效无损压缩。

**（一）物理预测模型体系**

**模型1：轨道热模型预测器（OTMP，Orbital Thermal Model Predictor）**

基于卫星轨道根数（半长轴a、偏心率e、轨道倾角i、升交点赤经Ω、近地点幅角ω、真近点角ν）推算卫星当前时刻的日照/地影状态，结合卫星各节点的热平衡简化方程，预测各测温点的温度：

```
温度预测公式（节点k在时刻t的预测温度）：
T_pred(k, t) = T_prev(k) + ΔT_model(k, t)

其中：
ΔT_model(k, t) = [Q_solar(t) + Q_albedo(t) + Q_IR(t) - Q_radiation(t) 
                  - Q_conduction(t) + Q_internal(k)] × Δt / C(k)

Q_solar(t)：太阳辐射输入功率（由日照状态决定，日照时有值，地影时=0）
Q_albedo(t)：地球反照辐射（由轨道几何关系计算）
Q_IR(t)：地球红外辐射（与轨道高度、地球表面温度相关）
Q_radiation(t)：节点k的热辐射散热功率
Q_conduction(t)：节点间热传导（由拓扑结构确定）
Q_internal(k)：节点k的内部耗散热（由设备工作状态确定）
C(k)：节点k的热容（星上固化常数）
Δt：采样周期
```

**模型2：电源系统预测器（PSP，Power System Predictor）**

```
太阳帆板输出电流预测：
I_pred(t) = I_stc × cos(α(t)) × η_temp × f_coverage

其中：
I_stc：标准测试条件下的额定电流（固化常数）
α(t)：当前时刻卫星对日角（由轨道根数计算）
η_temp：温度修正系数（由当前帆板温度计算）
f_coverage：遮挡系数（0=地影，1=全日照，0-1=半影）

母线电压预测（基于充放电模型）：
V_bus(t) = f(SOC(t), I_load(t), T_battery(t))
SOC(t) = SOC(t-1) + [I_charge(t) - I_load(t)] × Δt / C_batt
```

**模型3：姿态动力学预测器（ADP，Attitude Dynamics Predictor）**

```
姿态角速度预测（对地定向卫星，正常姿控模式）：
ω_pred(t) = ω_orbit + δω(t)

其中：
ω_orbit：轨道角速度（由轨道根数计算，约0.001°/s）
δω(t)：姿控系统扰动项（由控制律方程估算）

姿态角预测：
θ_pred(t) = θ_prev(t) + ω_pred(t) × Δt
```

**（二）模型同步机制（星地共享预测模型）**

PDC-OM要求星地两端的物理预测模型精确一致，否则预测值不同将导致残差计算错误，无法还原原始数据。模型同步方案如下：

（a）**轨道根数同步**：地面运控系统定期（如每天一次）通过TC上行注入最新轨道根数（CCSDS TC标准帧格式），星上轨道预报模块使用注入的轨道根数更新模型参数。地面解压缩端使用相同的轨道根数和相同的传播算法；

（b）**模型参数版本号**：模型参数（热容、导热系数、帆板效率等）以版本号标识，版本号在PDC-OM压缩帧帧头携带（4位），若地面检测到版本号不匹配，发出告警并触发模型参数上传；

（c）**模型算法固化**：预测算法的数学实现（积分步长、截断精度等）在卫星出厂时与地面软件严格同步，确保同等输入下输出一致。

**（三）残差自适应Golomb-Rice编码**

残差 r(k,t) = value(k,t) - T_pred(k,t) 的编码步骤：

**步骤1：残差符号映射（Z字形映射，使分布关于0对称）**

```
若 r >= 0：mapped_r = 2 × r
若 r < 0：mapped_r = 2 × |r| - 1
```

**步骤2：自适应Rice参数k选择**

```
当前预测精度σ（残差的估计标准差，星上实时计算）：
σ = sqrt(alpha × sigma_prev² + (1-alpha) × r² )  // 指数移动平均
其中 alpha = 0.9（平滑系数）

最优Rice参数k（基于σ的近似最优选择）：
k = max(0, round(log2(ln(2) × σ) - 1))

k的取值范围：k ∈ {0, 1, 2, ..., 7}（3位编码k，最大支持σ≈64倍量化单位）
```

**步骤3：Golomb-Rice编码**

```
quotient q = floor(mapped_r / 2^k)
remainder  r_mod = mapped_r - q × 2^k

编码输出：q个1位 + 1个0位（商的一元编码）+ k位二进制余数
示例：k=3, mapped_r=10
  q=1, r_mod=2 → 编码：1_0_010 = 6位
  （未压缩情况下，10通常需要4-16位，视量化精度）
```

**（四）轨道段感知的预测模型切换**

卫星在轨运行经历不同轨道段，各段的预测模型精度差异显著：

| 轨道段 | 预测模型适用性 | 残差典型值 | 推荐策略 |
|---|---|---|---|
| 正常日照段 | OTMP/PSP高精度 | 0.01-0.1°C/0.01V | 使用物理模型 |
| 入影/出影过渡（±5分钟） | OTMP精度下降 | 0.5-2°C | 使用自适应线性预测 |
| 地影段（稳定后） | OTMP高精度 | 0.01-0.1°C | 使用物理模型 |
| 轨道机动段 | ADP/PSP失效 | 1-10°C | 回退至简单DPCM |
| 帆板展开/收拢过渡 | PSP失效 | 大幅跳变 | 回退至全值传输 |

**轨道段感知的模型切换逻辑**：

```
星上模型选择器每帧执行：

1. 从轨道预报计算当前轨道段标签（ECLIPSE/DAYLIGHT/MANEUVER等）
2. 从当前帧残差方差估计当前预测误差σ
3. 选择规则：
   if σ > THRESHOLD_HIGH（默认=5%量程）：
       切换至简单DPCM（一阶差分）
   elif σ > THRESHOLD_MID（默认=1%量程）：
       切换至一阶线性预测（LPC）
   else：
       使用物理模型预测（PDC-OM）
4. 在压缩帧帧头的2位"预测模式"字段标记当前模式（0b00=物理模型，
   0b01=线性预测，0b10=简单差分，0b11=全值传输）
5. 地面解压缩端根据预测模式字段选择对应的解压算法
```

**（五）联合编码框架**

对于拥有多个测量参数的遥测系统，PDC-OM支持联合预测：相关性强的多参数（如同一舱板上的多个测温点）使用向量预测（多维OTMP），利用参数间的相关性进一步减小残差，残差向量采用KLT（Karhunen-Loève Transform，K-L变换）去相关后再分别Golomb-Rice编码。

### 3. 技术方案基础上的改进与变形

**（1）轨道根数的星上自主更新**

基础方案依赖地面定期注入轨道根数。改进方案中，星上GPS/BDS接收机实时测量轨道位置，星上轨道确定算法（如简化版EKF轨道滤波器）自主更新轨道根数，无需地面注入，提高模型同步的实时性和自主性。

**（2）深度学习预测器替代物理模型**

改进方案中，可用轻量级神经网络（如LSTM或Temporal Convolutional Network）替代解析物理模型作为预测器，通过大量历史遥测数据训练后部署到星上。优点：无需精确物理建模，自动学习复杂非线性规律；挑战：星上计算资源和存储资源需求较高，需配合神经网络轻量化技术。

**（3）残差的熵编码增强**

在Golomb-Rice编码基础上，引入上下文建模：统计相邻帧残差的条件概率分布，选择条件熵最小的编码符号表（类似CALIC图像无损压缩算法），进一步降低平均编码位宽。

**（4）物理模型参数的在线辨识与更新**

热容、导热系数、帆板效率等物理模型参数在卫星寿命期内因材料老化、帆板效率衰减等因素会发生变化。改进方案中，星上持续收集残差统计数据，通过在线最小二乘辨识算法（OLS）更新物理模型参数，保持预测精度。辨识结果定期通过遥测下传，供地面验证并同步更新地面解压缩端的模型参数。

**（5）多模型集成预测**

改进方案中，同时运行OTMP、LPC、DPCM三个预测器，每帧选择残差最小的预测器的输出，并在压缩帧中用2位标记所选预测器。这种"集成预测"策略能在各种工况下保证使用最优预测器，进一步提升压缩率的鲁棒性。

### 4. 有益效果

**有益效果：**

（1）**利用物理规律显著提升预测精度**：相比简单一阶差分（DPCM），物理模型预测器（OTMP）在正常轨道运行段对温度参数的预测精度可高出10-50倍（残差从0.5°C降低至0.01-0.05°C），对应Golomb-Rice编码位宽从8位降低至2-3位，实现约60%-75%的额外压缩增益。

（2）**压缩率与物理意义强结合**：物理模型压缩方案隐式地将轨道动力学知识编入遥测编码，压缩后的残差序列具有明确的物理意义（观测值与模型预测值之差），便于地面运控人员进行异常检测（大残差即意味着卫星行为偏离正常模型，是异常征兆的早期指示器）。

（3）**自适应策略保证全轨道段压缩有效性**：轨道段感知的模型切换机制保证了在入影/出影过渡、轨道机动等物理预测精度下降阶段能够自动回退到适合的压缩策略，不会因预测失效导致压缩失败。

（4）**兼容现有CCSDS压缩标准**：Rice编码部分与CCSDS 121.0-B完全兼容，新增的自适应k参数选择和物理预测器可以作为现有标准的扩展实现，工程集成风险低。

（5）**辅助遥测异常检测功能**：物理模型预测的残差序列可作为卫星健康状态的"异常指数"，当残差持续偏大时自动告警，实现压缩传输与健康监测的一体化，具有额外的工程应用价值。

（6）**对星上计算资源需求合理**：轨道热模型的简化计算版本（使用当前轨道段标签而非实时积分）仅需基本浮点运算，在典型星务处理器（如带FPU的ARM Cortex-R）上的计算开销约为100-500μs/帧，远低于遥测采样周期（通常≥125ms）。

## 六、具体实施方式

**具体实施方案如下：**

以某低轨卫星（轨道高度500km，轨道周期94.6分钟）热控系统的温度遥测压缩为例：

**参数设定**：
- 测温点数量：48个，采样率：1次/8秒，量化精度：0.1°C，量化位宽：12位（-204.8°C至204.7°C）；
- 压缩前带宽：48 × 12bit/帧 × 1帧/8s = 72bps（仅温度数据）；
- 目标：压缩至<15bps。

**步骤一：星上模型初始化**

星上遥测处理器加载初始轨道根数（发射前注入）和热模型参数（48节点热容、导热矩阵、外热流系数），初始化OTMP预测器状态。

**步骤二：正常日照段压缩**

轨道第1圈日照段（约50分钟），每8秒一帧：

（a）轨道预报器计算当前真近点角ν=30°（日照段），太阳辐射输入Q_solar=全功率；

（b）OTMP计算每个测温点的预测温度T_pred（48个值）；

（c）计算残差：典型值在[-0.08, +0.06]°C范围内（量化后为±1 LSB）；

（d）σ估计：σ≈0.04°C，Rice参数k=max(0, round(log2(0.693×0.04/0.1)-1))=max(0,round(-2.85))=0，即k=0；

（e）Rice k=0编码（Golomb编码）：residual=0（多数情况）→1位编码"0"；residual=±1→2-3位编码；

（f）平均编码位宽：约1.2位/参数，vs原始12位，压缩率≈90%；

（g）压缩后带宽：约72×(1-0.90)=7.2bps，达到目标。

**步骤三：入影过渡段切换**

轨道第1圈入影（约40分钟日照后），OTMP的外热流计算由Q_solar切换为0，但实际温度响应存在热时常数滞后（约5-15分钟），预测误差σ增大至≈0.3°C，k自动调整为2，平均编码位宽增至3-4位/参数，压缩率仍约67-75%，满足正常工作需求。

**步骤四：模型参数在线辨识示例**

运行100圈后，帆板效率因辐照老化下降3%，PSP预测电流持续偏高，σ增大。星上OLS辨识算法检测到η_temp需修正，自动下调3%并更新，同时通过遥测下传模型更新通知包（含新参数值和版本号），地面接收后同步更新。

## 七、技术创新点概括

本方案重点要保护如下几方面的创新点：

1）**将卫星轨道动力学/热力学/电气特性物理模型作为遥测压缩预测器的方法**：首次提出将解析物理模型（OTMP/PSP/ADP）内嵌于遥测编码器作为预测器，而非使用通用数学预测器，这是该领域的根本性创新。

2）**基于σ实时估计的自适应Golomb-Rice参数k选择方法**：指数移动平均估计残差标准差σ，并通过近似最优公式实时计算最优k值的自适应算法，优于固定块长统计的传统方法。

3）**轨道段感知的多模型切换与自动回退机制**：根据当前轨道段标签（日照/过渡/地影/机动）和实时残差方差σ，自动在物理模型/线性预测/简单差分/全值传输之间切换的决策机制。

4）**物理模型参数星地在线同步与辨识方法**：通过遥控上行注入和遥测下行回传实现物理模型参数的星地双向同步，及基于OLS的在轨参数辨识更新机制。

5）**联合预测中K-L变换去相关的多参数压缩方法**：利用相关测温节点间的联合预测和K-L变换去相关，进一步减小多参数联合残差熵的编码方法。
