## 一、发明/实用新型名称

**一种低轨卫星星座多星聚合EPFD协同规避与执行时序精度保障方法**

---

## 二、所属技术领域

本发明涉及卫星通信技术领域，特别是涉及一种适用于大规模低轨（LEO）卫星星座场景的、基于多星聚合等效功率通量密度（EPFD）协同规避的系统级频率协调方法，以及干扰规避配置指令从地面向卫星传输时的执行时序精度保障方法。

---

## 三、现有技术（背景技术）

### 背景技术

**多星叠加干扰问题**：LEO星座（如Starlink、GW等）由数百至数万颗卫星组成，当星座中多颗卫星同时飞越GEO卫星（地球静止轨道卫星）保护区域附近时，各星下行信号对同一GEO地球站产生的干扰功率叠加，形成"聚合干扰"。根据ITU-R S.1749建议书，EPFD（等效功率通量密度）是全星座所有卫星对GEO地球站干扰功率的系统性总和，ITU保护阈值的约束对象是全星座的聚合EPFD，而非单颗卫星的贡献值。

**信号传播时延问题**：在5G NTN（非地面网络）再生载荷架构中，地面卫星控制设备（SCF）通过馈电链路向星上基站（S-gNB）上注干扰规避配置指令。对于轨道高度500~1200 km的LEO卫星，信号单程传播时延约1.7~8 ms。除传播时延外，S-gNB解析指令需约5~20 ms处理时延，相控阵天线（PAA）权值切换需约0.5~5 ms响应时延，三者累计可达8~33 ms。

**现有最接近技术方案**：

（1）单星独立规避方案：SCF对每颗LEO卫星独立计算单星EPFD是否超过按比例分配的单星限值，超限则下发关断指令。各星独立执行，无跨星协调机制，无聚合EPFD感知能力，责任按静态均等分配（所有卫星获得相同的EPFD配额），不考虑各星的实际业务负载差异。

（2）固定时间提前量方案：部分系统采用固定的时间提前量（如固定提前3秒发送指令），粗略覆盖传播时延，但该提前量不随卫星轨道位置动态变化，也无执行偏差反馈机制。

**现有技术缺点**：

1. 单星独立规避无法保证系统聚合EPFD（AS-EPFD）合规：各星单独合规时，N星叠加的AS-EPFD仍可能超过ITU系统保护阈值，存在违规风险；

2. 静态均等责任分配忽视业务负载差异：重载卫星在承担规避时造成较大业务中断，轻载卫星的规避能力未被充分利用，系统整体业务损失偏大；

3. 固定时间提前量精度不足：传播时延随卫星位置动态变化（变化幅度约2~6 ms），固定提前量在卫星仰角低时可能不足，导致规避"滞后"，GEO保护窗口出现漏洞；

4. 无执行时序偏差反馈，错误无法自我修正。

## 四、发明/实用新型内容

### 1、要解决的技术问题

本发明要解决的技术问题是：

（1）如何建立多LEO卫星之间的聚合EPFD（AS-EPFD）实时监测机制，在系统级感知聚合干扰态势，确保ITU系统级合规性；

（2）如何在SCF层面建立动态、负载感知的多星规避责任分配协议，在满足系统级EPFD合规的前提下，最小化整体业务中断量；

（3）如何设计传播时延预补偿机制，将干扰规避执行时序精度从毫秒级提升至亚毫秒级；

（4）如何建立执行时序偏差的闭环反馈与自适应修正机制。

### 2、为解决技术问题而采用的技术方案

本发明提供一种多星聚合EPFD协同规避与执行时序精度保障方法，在卫星控制设备（SCF）中集成多星协调器（MSC，Multi-Satellite Coordinator）和时延预补偿模块，在星上基站（S-gNB）中集成时序预补偿单元（TPC，Timing Pre-Compensation Unit），通过扩展的S-C1接口消息实现协调控制。

#### 技术方案一：多星聚合EPFD实时监测与超限判断

SCF中的多星协调器（MSC）以周期T_coord（默认1~5秒）执行以下聚合EPFD计算：

（1）收集当前所有处于"干扰几何关系"（即飞越GEO保护区域附近，满足ITU规定共线条件）的LEO卫星集合，记为S_active；

（2）对S_active中每颗卫星j，根据其实时星历和波束配置，计算单星对目标GEO地球站的EPFD贡献值SS-EPFD_j；

（3）计算系统聚合EPFD：AS-EPFD = 所有S_active中卫星j的SS-EPFD_j之和（线性值相加，dB域转换为线性后求和）；

（4）判断：若AS-EPFD超过ITU系统保护阈值EPFD_th_sys，则触发多星协同规避流程。

#### 技术方案二：动态负载感知规避责任分配算法

当AS-EPFD超限时，SCF-MSC按以下算法在S_active中的N颗卫星间分配规避责任，目标是在使AS-EPFD降至合规水平的同时，最小化各星总业务中断量：

**步骤一：计算各星调度贡献优先级（SCP_j）**

```
ρ_j = SS-EPFD_j / AS-EPFD          （卫星j的EPFD贡献比例，范围0~1）
λ_j = 已用波束数_j / 总波束数_j    （当前业务负载率，由S-gNB周期上报）
SCP_j = α × ρ_j + (1-α) × (1 - λ_j)   （α为权重系数，默认0.6）
```

SCP_j越高，表示该卫星EPFD贡献大（应多承担规避责任）且业务轻载（规避时业务损失小），应优先被分配更多规避任务。

**步骤二：迭代分配IRL升级任务**

按SCP_j由高到低排序，依次对各卫星升级IRL等级（IRL-0→IRL-1→IRL-2→IRL-3），每次升级后估算新的AS-EPFD：

- IRL-1（旁瓣抑制）：该星EPFD贡献降低为 SS-EPFD_j × Δ_SL（旁瓣抑制后的EPFD衰减因子，约0.7~0.9，由天线特性校准）；
- IRL-2（方向性零陷）：该星EPFD贡献降低为 SS-EPFD_j × Δ_NS（零陷后衰减因子，约0.001~0.01）；
- IRL-3（完全关断）：该星EPFD贡献降为0。

迭代直至AS-EPFD ≤ EPFD_th_sys，输出各星对应的IRL等级。

**步骤三：协调配置下发**

SCF-MSC将各星各自的IRL等级配置通过S-C1接口分别下发至对应S-gNB，配置信息中新增以下协调标识字段：

- **Coord_ID（32比特）**：本次多星协调事件的全局唯一编号，同一事件中各星配置携带相同Coord_ID；
- **Coord_Duration（32比特，单位秒）**：本次协调配置的有效时长；
- **CES——本星EPFD分配份额（16比特，单位0.1 dBW/m²/MHz）**：分配给本星的SS-EPFD上限，供S-gNB本地参考；
- **Coord_Count（8比特）**：本次协调涉及的卫星总数。

**可选扩展——星间链路（ISL）辅助协调**：若LEO星座配备星间链路（ISL），S-gNB可通过ISL向邻星广播当前执行的IRL等级和实时业务负载数据，辅助SCF-MSC以更高频率（周期T_ISL < T_coord）修正协调决策，实现"分布式感知+集中管控"的混合架构。ISL协调数据帧包含：发送星ID、当前IRL等级摘要、负载率、本地计算的SS-EPFD。

#### 技术方案三：传播时延预补偿执行时序精度保障机制

规避指令从SCF生成到S-gNB实际执行，累计时延为：

```
T_total = T_prop + T_proc + T_PAA
```

- T_prop（传播时延）：= SCF馈电站至LEO卫星的斜距 R_feed / 光速c，随卫星位置动态变化，范围约1.7~8 ms；
- T_proc（指令处理时延）：S-gNB解析完配置包后L3层完成计算的时延，约5~20 ms，由S-gNB能力响应消息上报（字段：T_proc_cap）；
- T_PAA（天线切换时延）：PAA-CU完成权值切换的时延，约0.5~5 ms，由S-gNB在能力响应中上报（字段：T_PAA_cap）。

**SCF侧：实时计算T_comp并注入配置信息**

SCF在生成每次规避配置信息时，计算总时延预补偿值：

```
T_comp = T_prop(t_send) + T_proc_cap + T_PAA_cap + T_margin
```

T_prop(t_send)根据发送时刻的卫星星历实时计算，T_margin为安全余量（默认0.5 ms）。

在配置信息包中新增以下字段：

- **T_comp（32比特，单位微秒）**：总时延预补偿值；
- **TD_Valid（1比特）**：1表示本包含有效T_comp，S-gNB应执行预补偿；0表示忽略（兼容旧版）；
- **Gen_Timestamp（64比特，单位纳秒，使用GNSS时间）**：SCF生成本配置包时的绝对时间戳，供S-gNB验证时效性。

**S-gNB侧：时序预补偿单元（TPC）执行流程**

S-gNB的TPC集成于L3层，执行以下步骤：

① 读取TD_Valid字段，若有效则继续执行预补偿；

② 读取Gen_Timestamp，与本地GNSS时间对比，若差值超过T_comp × 2（包传输时延异常），则丢弃T_comp、向SCF上报时效警告；

③ 对配置中每个规避时段[start, end]，计算补偿后时刻：
```
start' = start - T_comp
end'   = end   - T_comp
```

④ 以补偿后的[start', end']作为L2调度关断和PAA-CU权值切换的实际触发时刻；

⑤ 若提前量充足（start' - 当前时刻 > T_PAA_cap + T_margin），PAA-CU在start' - T_PAA_cap时刻预加载权值（不发射，权值就绪），在start'即时激活。

**闭环反馈与自适应修正**

S-gNB记录实际执行时刻T_exec，计算偏差ΔT = T_exec - start'（正值为滞后，负值为超前），在管理响应消息中附加"执行时序偏差上报"字段（含Reported_Config_Ver版本号和Delta_T值，单位100微秒）。

SCF收到ΔT后，按以下公式自适应修正T_margin：

```
T_margin_new = T_margin_old + β × ΔT    （β为学习率，默认0.3）
T_margin_new = clip(T_margin_new, 0, T_margin_max)
```

经数次迭代后T_margin收敛，系统执行时序误差可控制在±0.5 ms以内。

### 3、在本发明技术方案基础上的改进与变形

（1）**分布式协调替代集中式MSC**：各LEO卫星S-gNB通过ISL相互通信，基于分布式共识算法（如分布式拍卖或博弈论机制）自主协商各星规避责任，无需SCF-MSC集中仲裁，适用于馈电链路时延较大或SCF失联场景；

（2）**SCP_j分配函数变形**：分配优先级函数可替换为非线性形式（如指数加权、神经网络推断）或加入更多维度（如候选目标波位数量、用户QoS分布），以实现更精细的业务损失最小化；

（3）**T_comp各分量的自主测量**：S-gNB可集成传播时延自主测量能力（如利用GNSS时间戳往返测量替代SCF下发T_prop分量），与SCF下发的T_proc和T_PAA分量结合，实现混合时延补偿；

（4）**更细粒度的时效性验证**：当SCF检测到Gen_Timestamp时效性异常时，可自动发起重传或重新生成配置，避免使用过期时延参数；

（5）**Coord_ID扩展为协调序列号**：用序列号替代事件ID，使SCF-MSC能追踪每次协调指令的执行状态，对未确认的协调配置自动重发。

### 4、有益效果

（1）**系统级ITU合规性主动保障**：现有单星独立规避无法保证AS-EPFD系统级合规，本发明通过SCF-MSC实时监测AS-EPFD并主动协调各星IRL等级，将系统合规保障从被动的概率性合规升级为主动的确定性保证，消除潜在的ITU违规风险；

（2）**整体业务损失最小化**：SCP_j动态分配算法优先让轻载、高贡献度卫星承担更多规避任务，相比静态均等分配，在相同AS-EPFD降低目标下可减少整体业务中断量（估计约20%~40%，依实际负载分布而定）；

（3）**执行时序精度大幅提升**：T_comp预补偿机制可将执行时序误差从现有技术的约8~15 ms降低至±0.5 ms以内，满足5G NR 1 ms子帧调度精度要求，避免规避"滞后"导致GEO保护窗口出现空白；

（4）**闭环自学习持续保持精度**：ΔT反馈和T_margin自适应修正机制使系统在长期运行中持续优化时序精度，适应S-gNB处理时延漂移和PAA硬件老化变化，无需人工重新标定。

## 六、具体实施方式

以3颗LEO卫星同时飞越某GEO卫星（定点经度100°E）保护区域为例，说明本发明的具体实施过程。

**场景设定**：3颗LEO卫星（标记为Sat-A、Sat-B、Sat-C）同时进入GEO保护区域，各星业务负载率分别为：λ_A = 0.3（轻载）、λ_B = 0.7（重载）、λ_C = 0.5（中载）。当前各星对目标GEO地球站的SS-EPFD贡献值：SS-EPFD_A = -162 dBW/m²/MHz，SS-EPFD_B = -163 dBW/m²/MHz，SS-EPFD_C = -164 dBW/m²/MHz，折算为线性值后求和得AS-EPFD超过ITU系统保护阈值EPFD_th_sys = -160 dBW/m²/MHz。

**步骤一：SCP_j计算与排序（SCF-MSC）**

各星EPFD贡献比例（ρ）和SCP_j（α = 0.6）：

| 卫星 | SS-EPFD（线性比例ρ_j） | 负载率λ_j | SCP_j = 0.6×ρ_j + 0.4×(1-λ_j) |
|-----|------|------|------|
| Sat-A | 约50% | 0.3 | 0.6×0.50 + 0.4×0.70 = 0.58 |
| Sat-B | 约32% | 0.7 | 0.6×0.32 + 0.4×0.30 = 0.31 |
| Sat-C | 约18% | 0.5 | 0.6×0.18 + 0.4×0.50 = 0.31 |

按SCP_j降序：Sat-A（0.58）> Sat-B（0.31）≈ Sat-C（0.31）。

**步骤二：迭代分配规避责任（SCF-MSC）**

首先对SCP_j最高的Sat-A升级IRL至IRL-2（方向性零陷），估算其EPFD贡献降低至 SS-EPFD_A × Δ_NS = SS-EPFD_A × 0.005，重新计算AS-EPFD，若仍超限则继续对Sat-B升级至IRL-1（旁瓣抑制），估算其贡献降低至 SS-EPFD_B × Δ_SL = SS-EPFD_B × 0.8，再次计算AS-EPFD，若此时AS-EPFD ≤ EPFD_th_sys则分配结束；否则继续对Sat-C升级。本例中经前两步即可使AS-EPFD满足合规要求，结果：Sat-A执行IRL-2，Sat-B执行IRL-1，Sat-C维持IRL-0。

**步骤三：协调配置下发（SCF-MSC）**

SCF-MSC生成Coord_ID = 0x12345678，分别向Sat-A下发IRL-2配置（含Coord_ID、CES分配份额等字段），向Sat-B下发IRL-1配置，向Sat-C下发正常工作配置（无规避）。

**步骤四：时延预补偿计算与执行（Sat-A为例）**

当前时刻Sat-A的馈电站至卫星斜距R_feed = 800 km，T_prop = 800000 m / 3×10^8 m/s ≈ 2.67 ms；Sat-A上报的T_proc_cap = 10 ms，T_PAA_cap = 1 ms；T_margin = 0.5 ms。

SCF计算：T_comp = 2.67 + 10 + 1 + 0.5 = 14.17 ms ≈ 14170 μs，写入配置信息，同时附上Gen_Timestamp（当前GNSS绝对时间）。

Sat-A S-gNB的TPC接收配置后，对规避时段[start, end]计算补偿值：start' = start - 14.17 ms，end' = end - 14.17 ms，以[start', end']触发L2调度关断和PAA-CU权值切换，使实际执行时刻与设计时刻误差在±0.5 ms以内。

**步骤五：闭环校正**

Sat-A S-gNB测量实际执行时刻偏差ΔT = +0.3 ms（轻微滞后），通过管理响应消息上报SCF，SCF修正：T_margin_new = 0.5 + 0.3 × 0.3 = 0.59 ms，在下一轮配置中使用更新后的T_margin，逐步收敛。

## 七、技术创新点概括

本方案重点要保护如下几方面的创新点：

1）**多星聚合EPFD（AS-EPFD）实时监测与系统级超限判断机制**：SCF-MSC以固定周期聚合S_active集合中所有卫星的SS-EPFD_j，计算AS-EPFD并与ITU系统保护阈值比较，首次在星地控制层实现系统级聚合EPFD的实时感知，弥补了单星独立评估无法保证系统级合规的根本缺陷；

2）**基于SCP_j（调度贡献优先级）的动态负载感知规避责任分配算法**：综合各星EPFD贡献比例（ρ_j）和业务负载率（λ_j），计算SCP_j = α×ρ_j + (1-α)×(1-λ_j)，按SCP_j降序迭代分配IRL升级任务，实现在满足AS-EPFD合规约束下的业务损失最小化；

3）**协调配置扩展消息字段设计**：Coord_ID（协调事件唯一标识）、Coord_Duration（协调有效期）、CES（本星EPFD份额分配）、Coord_Count（协调星数）四个新字段，使多星协调事件具备全局可追踪性；

4）**实时T_comp传播时延预补偿机制**：SCF根据实时星历动态计算T_prop，联合T_proc_cap和T_PAA_cap形成T_comp，携带Gen_Timestamp注入配置信息，S-gNB-TPC据此对规避时段超前触发，将执行时序误差控制在±0.5 ms以内；

5）**ΔT闭环反馈与T_margin自适应修正机制**：S-gNB上报实际执行时序偏差ΔT，SCF以学习率β动态修正安全余量T_margin，实现系统时序精度的持续自优化，无需人工重新标定。
