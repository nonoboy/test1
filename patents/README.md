## 技术指标汇总

| 专利 | 典型场景压缩率 | 星上复杂度 | 兼容CCSDS |
|---|---|---|---|
| 专利1（PVLC） | 85-95% | 低（整数运算） | 是 |
| 专利2（协商） | N/A（使能机制） | 极低 | 是 |
| 专利3（HCP） | 79-93%（头部） | 极低 | 是 |
| 专利4（PDC-OM） | 60-85%（B级参数） | 中（浮点运算） | 是 |
| 专利5（PACT） | 系统级优化 | 低 | 是 |
| 专利6（BITM） | 90-95%（整帧） | 极低（位运算） | 是 |

**联合使用（专利1+3+6）最优效果**：整体遥测帧压缩率可达95%-98%，同等4kbps带宽下可监测慢遥参数数量从约100个提升至约2000个。

## 核心技术对标

| 本专利系列技术 | 对标地面通信技术 | 核心差异化创新 |
|---|---|---|
| PVLC参数分级 | ROHC上下文压缩 | 面向遥测语义（非协议头），引入参数波动性分级 |
| TC/TM协商 | TLS握手/ROHC反馈 | 利用遥控上行作为反向信道，处理大时延异步场景 |
| CCSDS-HCP | 3GPP ROHC | 针对CCSDS空间包序列号固有递增特性的专项设计 |
| PDC-OM物理预测 | LPC线性预测编码 | 引入轨道动力学物理模型代替通用数学预测器 |
| PACT调度 | 5G NR QoS调度 | 针对单向异步遥测+弧段有限带宽的专项设计 |
| BITM位图帧 | USB HID输入报告 | 扩展至多字节数值参数+字典同步+在轨热更新 |
